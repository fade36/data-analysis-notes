## Commit History:
### Useful parameters

- git log -p -2:
	-p is -patch: returns difference implemented in every commit
	-2: limits amount of commits

- git log --stat:
	--stat: returns short statistics about commit

- git log --pretty:

- =oneline:
	returns every commit in one row in format: hash + description

- =format:
Example:
`git log --pretty=format: "%h - %an, %ar : %s"`
Output:
ca82a6d - Scott Chacon, 6 years ago : Change version number

#### Format table:

- %H		commit hash
- %h		short commit hash
- %T		tree hash
- %t		short tree hash
- %P		parent hash
- %p		short parent hash
- %an		author name
- %ae		author email
- %ad		author date
- %ar		relative author date
- %cn		commiter name
- %cd		commiter date
- %s		description


-  git log --pretty=format:" " --graph:
	shows branches and merges in ASCII graph format
