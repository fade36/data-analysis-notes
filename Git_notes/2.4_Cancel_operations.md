## Cancel operations

- git commit --amend Example:

- To add forgotten files:
`
$ git add abc.c def.c
$ git commit -m 'Initial commit'
$ git add forgotten_file.c
$ git commit --amend
`

- To rewrite commit description:
`
$ git add abc.c def.c
$ git commit -m 'Initial commit'
$ git commit --amend -m "New decription"
`

- git restore --staged file.md:
	to unstage files from git add

- git restore file.md:
	to discard changes in file.md
